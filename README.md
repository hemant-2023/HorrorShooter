# Horror FPP Shooter

A horror-themed first-person shooter game made in Unity. Explore dark corridors, survive enemy attacks, and manage your health and ammo.

## 🔫 Features
- FPS Controller with weapon mechanics
- Enemy AI: chase and attack logic
- Health and damage system
- Jumpscare triggers
- Death and respawn

## 🛠 Tech Used
- Unity Engine
- C#
- Unity's FPS input system
